# Security policy

This repository is a research and education simulator, not a secure federated-learning
deployment. It does not provide secure aggregation, transport encryption, client
authentication, differential privacy, or protection from malicious serialized model
files.

Do not open untrusted `.pt` or `.pth` files. Report a suspected code-execution,
dependency, or credential-exposure issue privately through GitHub's security advisory
feature rather than a public issue.
